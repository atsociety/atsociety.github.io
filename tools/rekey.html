Board manual — edit content or change the password

This tool updates the password-protected board page without any coding. It runs entirely in your browser — nothing you type is sent anywhere. You'll need the current board password.

1Load the current board page file

Get the file board/index.html from the club's GitHub repository: open the repo → board folder → index.html → the Download raw file button (top right of the file view). Then choose it here. No access to the club's GitHub yet? Ask the President to add you — it takes a minute.

2Unlock it


3Edit the manual (optional)

Click into the text below and edit it like a document. Keep the section headings — they become the page's menu. If you only want to change the password, leave the text as it is.

4Set the password

Leave both boxes empty to keep the current password. At handover each year, set a fresh one here.

5Generate the updated file

Relax — this only downloads a file to your computer. Nothing on the live site changes until you upload it in the next step, and even then GitHub keeps every old version under the file's History, so any mistake can be undone.

Last step — put the new file on the site:
  1. Open the club's GitHub repository and go into the board folder. Important: the address bar must end in /board before you upload — uploading this file at the top level of the repository would replace the site's homepage, because both files are named index.html.
  2. Open index.html → click the pencil (Edit) → select everything and delete it.
  3. Open the file you just downloaded in a text editor (Notepad / TextEdit), select all, copy, and paste it in. Or: in the board folder choose Add file → Upload files and upload the download — it replaces the old one because the name matches.
  4. Click Commit changes. The live site updates in about a minute.
  5. If you changed the password, share the new one with the board privately (not in writing on the site or repo).
